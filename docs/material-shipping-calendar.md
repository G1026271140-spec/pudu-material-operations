# 物料发货日历

入口：数据与系统工具 → 物料管理 → 物料发货日历。
路由：`/management/shipping-calendar`。权限：已启用的管理员。

## 展示口径

数据直接读取虚拟机 PostgreSQL 申请单和申请明细；不用页面业务缓存。
仅展示普通物料申请、库存审查状态为“已核实库存”，并排除撤回、驳回、取消中的单据。
未发货和已发货分两列，以原申请单的“是否发货”复选框区分，不能由有无运单号推断。
日历按北京时间计算“今天”；可切换计划发货日、要求到达开始日。
缺少当前依据日期的申请单保留在未设置日期分组；整月视图同时显示这些单据。
支持全部日期及单号、申请人、物料、物流信息搜索。
卡片同时显示发货日与到达日，详情显示全部申请明细和收件信息。
超过计划发货日但未发货的单据显示提示；已发货单据不显示逾期提示。

## 保存和同步

一次保存三个发货字段，并在同一短 SQL 事务中写入审计、幂等结果和 ordinary lane outbox。
事务内没有飞书 HTTP 请求。保存返回后页面立即反映本地结果；worker 异步发布到同一申请单。
上传图片先持久化到共享媒体目录及本地媒体表，再由 outbox worker 上传到飞书。
支持 PNG/JPEG/WebP，单张最多 6 MB、2400 万像素、每单最多 12 张。
新增附件必须归属当前上传人，已有附件只能保留当前申请单关联的附件。
图片接口全部要求管理员，已保存图片还需验证与申请单的关联，禁止跨单附件注入。
版本检查防止陈旧窗口覆盖新值，幂等标识防止网络重试产生重复写入。
飞书人工修改冲突沿用 outbox 冲突策略；不能静默覆盖。
每天 03:00 Asia/Shanghai 的原核对任务继续以飞书为准回写本地，这三个已注册字段自然纳入。
发货编辑不扣减库存、不改变审批状态或申请数量、不主动发送员工通知。
