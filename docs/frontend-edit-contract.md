# 页面业务字段编辑约定

本文件对应 2026-10-26 当前 React 页面。发货模板、发货排期保持现状，不为这两个附加功能建立字段定义。

完整稳定字段 ID、字段类型、SQL 列及实际下拉选项见 [主业务字段映射](frontend-field-map.md) 和 `config/frontend_field_contracts.json`。本文约定编辑入口及派生关系，不表示所有入口已经上线。

## 品类、型号、语种与战区

| 页面对象 | 当前展示或输入字段 | 飞书来源 | 编辑方式 |
|---|---|---|---|
| 品类基础信息 | 品类名称、中英文页面名称、品类定义、商业发票产品名称、装箱单产品类型、启用状态、申领页显示、无需型号、无需语种、美元单价、海关编码、备注 | 物料品类同名字段 | 管理员输入/单选；名称、定义及维度变更通过品类同步服务处理关联物料 |
| 品类图片 | 图片列表、图片名称及显示顺序 | 物料品类／申领页图片 | 新建选填；编辑支持添加、移除、替换；未操作时保持原值；仅修改图片，不删除 GLB/HTML 等其他附件 |
| 品类人民币价格 | unit_price_rmb、卡片人民币单价 | 物料品类／单价（人民币） | 飞书公式字段，修改美元单价；当前实际公式为美元价 × 6.77，本地采用同一公式反馈显示 |
| 品类关联组合 | 型号、语种或战区及其物料行 | 主数据/文化周边库存的维度字段、关联字段 | 管理员选择维度；通过原品类组合服务新建/更新对应物料行，不直接覆盖关联反向字段 |
| 型号 | 名称、中英文页面名称、产品线、型号类型、状态、关联品类 | 产品型号／产品型号、中文页面名称、英文页面名称、产品线、型号类型、启用状态，以及关联物料 | 管理员编辑；选项取实际字段元数据；名称变更需同步关联记录 |
| 语种 | 名称、状态、关联品类/型号组合 | 物料语种／语言种类、启用状态，以及关联物料 | 管理员编辑及关联服务；页面显示的“语种”对应实际字段“语言种类” |
| 战区 | 名称、状态、关联品类/型号组合 | 战区管理／战区名称、启用状态，以及文化周边关联 | 管理员编辑及关联服务 |
| 系统元信息 | record_id、自动编码、创建时间、SQL 版本、任务状态 | 记录 ID、自动编号或本地系统字段 | 系统生成；业务字段编辑后自动更新 |

## 普通物料与文化周边库存

| 页面对象 | 字段 | 飞书来源 | 编辑方式 |
|---|---|---|---|
| 普通物料 | material_code、category、model、language、quantity、in_transit_quantity、unit_price、customs_code、status、request_visible、remark | 物料主数据／物料编码、物料品类、产品型号、语种、当前库存、在途库存、单价（美元）、海关编码、启用状态、是否在申领页显示、备注 | 基础信息由管理员编辑；库存变更通过库存调整/补库/配货事务，同时产生库存流水 |
| 普通物料人民币单价 | unitPriceRmb、unit_price_rmb | 物料主数据／单价（人民币） | 编辑美元价格后计算，保留与飞书公式相同的依赖关系 |
| 库存金额和差额 | total_value、当前库存总计、目标库存总计、库存差额、组合数量 | 数量、单价及当前目标组合 | 本地派生；通过编辑数量、价格或组合更新 |
| 文化周边 | material_code、category、model、region、quantity、unit_price、remark | 文化周边管理库存／文化周边编码、物料品类、产品型号、战区管理、当前库存、单价（人民币）、备注 | 管理员编辑，库存走流水事务；共享编辑器中的 language 实际对应战区管理 |
| 文化周边状态与可见性 | status、request_visible | 当前共享编辑器使用固定“启用/显示”默认值 | 不是已存在的独立库存字段；品类启用和显示规则在品类表维护，不虚构相同字段 ID |
| 目录卡片 | 品类名称、定义、图片/模型、中英文名称、型号显示名、产品线、可选规格、价格、库存 | 品类、型号及上述库存表联结 | 编辑上述来源；搜索词、排序、展开状态和购物车选择是页面状态 |

## 申请与配货

| 对象 | 当前字段 | 飞书来源/本地含义 | 编辑及校验 |
|---|---|---|---|
| 申请身份 | requester、requester_open_id、department、department_id、submitter、submitter_open_id | 物料申请单／申请人、申请部门\|区域、提交人；部门 ID 为通讯录标识 | 在业务权限范围内选择申请人；提交人取真实登录身份；组织名称、路径和人员身份来自通讯录，不能在页面伪造登录人 |
| 普通申请内容 | title、customer_name、country、recipient_info、freight_payer、material_usage、request_reason | 物料申请单／标题、客户名称、国家、收件人信息、运费承担者、物料用途、申请原因；兼容旧备注来源 | 文本/实际选项编辑；保留必填、用途、身份及角色校验 |
| 计划时间 | arrival_start、arrival_end、required_arrival_start/end、material_usage_time、预计最晚下单日、时效判断 | 要求达到开始日期、要求到达结束日期、物料使用时间及既有时效字段 | 编辑来源日期和原因后重新校验；自动判断和颜色说明由规则计算 |
| 申请行 | product、model、language/region、quantity、remark、is_custom_material、source、admin_only | 申请明细的物料/文化周边关联、品类名称、产品型号名称、语种名称、文化周边战区、申请数量、备注、明细业务类型 | 选择对应库存记录；数量正整数；定制物料、管理员代申请及文化周边额度保留原规则 |
| 申请价格快照 | unit_price_rmb、subtotal_rmb、request_total_rmb | 申请明细／申请时单价（人民币）、金额小计（人民币）；物料申请单／费用合计（人民币） | 选物料和数量后在同一业务事务生成快照与汇总；不是修改当前库存单价即可重写历史费用 |
| 库存快照/现值 | stock_snapshot、current_stock、in_transit_stock、inventory_status、库存审查结果 | 提交时库存快照、主数据当前/在途库存、库存审查状态与结果 | 来源数量改变时重算；历史提交快照通过业务更正流程保留审计，不作为自由输入框 |
| 审批 | status、approved_at、approval_comment、approved_qty、审批实例 | 申请单审批状态/时间/意见；明细审批通过数量及审批关联 | 原审批/管理员流程处理；保留允许的状态转换、数量上限和权限 |
| 库存复核 | inventory_review_status、inventory_review_reminder_at、reminder_status、operator、review_version、change_note | 申请单库存审查状态/提醒时间/提醒状态、库存审查人、后台编辑版本、配货调整及原因 | 管理员或合法配货卡片入口；版本冲突拒绝覆盖；提醒时间可在允许流程内编辑 |
| 配货行 | actual_product/model/language/material_code、actual_issue_qty、original_quantity、物料调用状态、是否下单、拆单数量、到货/发货相关状态与时间 | 申请明细实际发放字段、原申请数量及现有订单/调用字段 | 配货台编辑、确认、拆单或撤销；库存和流水同事务，不能重复扣减；普通物料和文化周边可并发，竞争同一资源时协调 |
| 执行状态 | request_no、line_no、taskId、提交/完成时间、处理进度、通知结果 | 申请单/明细编号、持久化任务及本地同步状态 | 系统生成；本地已保存、后台处理中、飞书已同步、失败/冲突分别展示 |

## 企业文化衫与权限

| 对象 | 字段 | 来源 | 编辑方式 |
|---|---|---|---|
| 企业文化衫目录 | product/source_style、size、code、available/latest_inventory、system_redeemed、images | 行政源表／款式、码数、编码、最新库存、系统兑换数量、图片；主库副本的 SourceID 指向行政源记录 | 已用现有应用身份核对行政源表 16 个实际字段并单独映射；最新库存为公式，修改原始库存数量、入库/纠正、兑换来源后计算，不向主库同步副本随意改写 |
| 企业文化衫申请 | 申请人、部门、用途/展会、申请原因、款式、尺码、数量 | 物料申请单/申请明细及文化周边兑换／申请人、兑换人、兑换方式、申请用途、款式、码数、数量 | 原申领、兑换和撤销流程；申请原因保留现有可选项及校验 |
| 个人额度 | 已领数量、剩余额度、角色、是否启用 | 用户权限表／各款式申领数量累计、角色、是否启用 | 管理员维护权限；领取与撤销按申请人及款式加锁更新累计数；上限属于业务规则，不冒充飞书现有字段 |
| 个人信息显示 | 姓名、头像、部门名称/路径、语言 | 飞书真实登录资料、通讯录和页面语言设置 | 登录和组织资料同步；仅业务申请人选择可编辑，不开放修改真实登录身份 |

## 保存与校验

- 通用字段注册支持文本、数字、实际单选/多选、日期、人员、附件、单向/双向关联；引用/公式通过源字段入口修改，自动编号和系统元数据自动维护。
- 企业文化衫的实际源表最新库存 = 原始库存数量 + 入库/纠正 - 表格兑换数量 - 系统兑换数量；表格兑换数量来自行政兑换表查找汇总。源表与营销主库副本的同名字段保留不同的表 ID/字段 ID，不能混用。
- API 中的 position 为旧兼容占位，当前申请表没有岗位/职位字段，现有页面没有该输入；申请明细 usage 的旧占位同样不能冒充独立字段，实际用途在所属申请单的物料用途字段。
- 字段 ID 和记录 ID 是核对主键，中文字段名仅作显示；原始多值 JSON 与类型化 SQL 列一并保留。
- 普通前端保存以 PostgreSQL 已提交事务为准；业务变更、审计和待同步任务应同事务提交。不要在飞书尚未完成时显示“已同步”。
- 每日北京时间 03:00 的校验以飞书为准，采用字段差异和版本保护；旧待同步任务不能覆盖已采纳的飞书手工修改。本地未同步的新建记录单独保留核对。
- 当前已建立字段注册和 SQL 投影；页面全面切换、业务事务通道及 03:00 定时作业仍按迁移阶段验证后启用。本文不能作为已上线验收记录。
