# 字段映射与品类图片阶段验证

核验日期：2026-10-26。开发分支：`codex/postgres-core`。公开页面仍为 V3.5.3 只读浏览，未切换数据库读写。

## 已落地

- 虚拟机 PostgreSQL 16.15：`pudu_materials`、`pudu_materials_test` 均建立 23 张来源表、358 个类型化字段列。
- 主业务库 22 张表/342 字段；使用同一现有应用身份补充核对企业文化衫行政源表 1 张/16 字段。
- 飞书表 ID/字段 ID、来源键、原表名、字段类型、实际选择选项、编辑控件、来源依赖和权限路径保留在注册文件中；同名源表与同步副本以不同表 ID 和来源键区分。
- 前端字段说明覆盖申请、配货、品类、型号、语种、战区、库存及文化衫；发货模板、发货排期按用户要求排除，相关实现文件无变更。
- 品类图片代码支持可选上传、预览、添加、移除和清空；不传图片变更时保持原值，图片编辑保留其他附件，拒绝过期图片版本覆盖。
- 上传图片先写本地文件及 PostgreSQL 元数据；Worker 记录飞书附件标识供重试复用。需要启用 `PUDU_DATABASE_DSN`、`PUDU_MEDIA_ROOT` 后才在管理目录显示该入口。
