# 虚拟机数据库迁移执行约定

核对日期：2026-10-27。本阶段发布目标 V3.6.2；本文件记录本轮用户确认的迁移要求。

## 数据归属

- 前端提交以虚拟机 PostgreSQL 的已提交事务为准，页面立即显示持久化结果与同步状态。
- 业务更新和待同步任务在同一事务中提交，Worker 随后同步飞书；本地已保存与飞书已同步分别展示。
- 每天北京时间 03:00 校验飞书多维表格与本地数据库；差异以飞书当前值为准，包括飞书中的手工修改。
- 校验期间处理版本冲突，已采纳飞书值的记录不能被旧待同步任务再次覆盖。未同步的新建记录保留并单独核对，不作为飞书删除记录处理。
- 同步保存字段级差异、前后值、业务版本、任务幂等键、来源及时间；不通过覆盖整张表解决冲突。

## 并发

- 普通物料申请与文化周边申请为两条业务通道，允许并发执行。
- 同一库存或同一申请人的文化周边额度按资源串行；共享用户权限记录需要单独协调。
- 通知任务独立，不阻塞业务写入；重试必须幂等，不能重复扣库或重复累计额度。

## 字段映射与编辑

- 盘点当前前端所有业务显示字段，记录页面、字段键、飞书表 ID、字段 ID、名称、类型、SQL 列、编辑方式、权限、校验及同步规则。
- 稳定字段 ID 用于映射；中文列名变化不能导致新建重复字段或丢失对应关系。
- 可写业务字段对应编辑控件；公式、汇总、查找与系统生成字段记录源字段及编辑路径，不直接覆盖只读计算结果。
- 品类创建增加可选图片；品类编辑支持新增、替换、移除当前图片。未修改图片时保留原附件；图片与 GLB/HTML 附件分别处理，避免误删。
- 新增与修改先在本地持久保存并返回新版本，前端局部更新；飞书同步及每日核对按同一映射执行。
- 2026-10-26 用户明确排除：发货模板、发货排期保持现状，均不创建数据库或飞书字段定义，也不改造其现有功能。
- 2026-10-27 用户新增发货模板要求：分摊 Shipping Cost 后的导出单价最多两位小数，允许发票小额尾差；此项覆盖此前不改发货模板的范围约束，仍不为其增加业务字段定义。

## 执行阶段

1. 资源检查、PostgreSQL 安装与本机应用角色：已完成。
2. 实时飞书 schema 导出、前端字段清单和对应关系：已形成可核对清单，含行政源表与同名副本区分。
3. 合计 23 张来源表、358 个稳定字段 ID 与类型化 SQL 列；5,452 条业务记录已导入并完成内容校验，页面读取已接通。工作台修改的审计及 outbox 同事务保存，飞书同步及日校验机制待实施。
4. 普通申请完整链路与两通道并发验证：待实施。
5. 管理员数据库工作台、字段编辑权限、品类图片编辑和页面版本更新已接通；申请/配货等受保护流程的正式提交继续按后续阶段处理。
6. 全量校验、备份恢复及切换验收后，再启用正式写入与 03:00 定时校验。
