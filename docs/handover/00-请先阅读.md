# PUDU 营销物料管理系统 · 数字化运营交接包

交接基准日期：2026-10-23。应用版本：V3.4.5。本包用于内部技术交接，不是生产数据库备份，也不会自动接管当前服务。

## 包内目录

| 目录 | 内容 |
| --- | --- |
| `01-source` | 正式版本源码、React 构建产物、测试、业务模板、Windows 部署和自动化脚本；不含密钥和真实业务缓存 |
| `02-documents` | 当前架构、配置清单、部署迁移、后台任务、运维和验收说明 |
| `03-installation` | 从交接源码重新构建的 Windows 配置启动器及其安全项目载荷；不沿用含业务缓存的旧 EXE |
| `04-verification` | 采集时的版本/计划任务/健康检查、文件清单、SHA-256、排除和修改记录、打包校验结果 |
| `05-optional-assets` | T300 / CC1 源模型转换后的独立三维演示附件，尚未替换应用内展示 |
| `06-unreleased-drafts` | 尚未被正式入口引用的本机前端草稿，单独保存，不属于正式部署版本 |

接手顺序：先读 `01-系统说明.md` → `03-配置与权限交接.md` → `02-部署与迁移.md` → `04-自动化与运维.md` → `05-验收与注意事项.md`。

## 必须另行交接的内容

1. 私有 GitHub 仓库访问/维护权限，以及缓存自动更新所需的推送权限。
2. 飞书“营销物料管理系统”自建应用的维护权限、App Secret、主 Base/行政源 Base 权限、审批与机器人配置。
3. Cloudflare 账号/域名管理权限、Named Tunnel 运行 Token，以及两个内部同步接口的回调密钥。
4. 正式切换时的受限运行状态备份：待处理本地动作、通知补发记录、删除日志、自动化去重状态及权限份额覆盖文件。它们不是可随便丢弃的普通缓存。

以上内容不放进普通 ZIP。请由当前负责人通过公司密码库或独立加密文件移交，不要与密码在同一渠道发送。启动器支持加密 `.pudu-migration` 配置导入/导出，但本次未生成包含现有凭据的迁移文件。

## 重要边界

- 当前正式系统是 **React + FastAPI + Windows Worker + 飞书多维表格 + Cloudflare Tunnel**；旧 README/DEPLOYMENT 中的 Streamlit 运行入口、管理员密码、唯一数据库等说法不完整或已过时。以本目录交接说明为准。
- SQLite 位于部署服务器，不在每个访问者的电脑里；所有用户通过同一个服务访问它。
- 清理后的包刻意不带人员和申请缓存。未完成配置和缓存初始化前，不能以“页面能打开/health 正常”认定业务已就绪。
- 当前源码包保留已提交的内网业务资源标识和产品素材，只供数字化运营内部使用，不能直接公开。
- 本次没有停止当前服务、迁移域名、修改飞书数据或变更生产版本。
