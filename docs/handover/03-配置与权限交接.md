# 配置与权限交接

## 配置文件

- `config/project_config.json`：非密钥配置，含仓库/分支、域名、端口、Runner 根目录、飞书表名及行政源表 ID、任务名/时间。保留当前值方便同环境接管；公司内部资源定位符不等于访问凭据。
- `.streamlit/secrets.toml`：敏感配置。虽然目录名仍叫 Streamlit，FastAPI/Worker/业务模块仍读取它，不可改目录名后不改代码。
- `extensions/material-automation/config.toml`：扩展单独配置。交接包只含 example；素材目录、凭据绝对路径和源表 ID 需复核。英文同步脚本目前直接按绝对路径读取 credentials_file。
- Runner 根目录的 `secrets.toml`、Web 根目录 `cloudflare-token.txt`：安装产生的受限副本，不在普通 ZIP 中。

## Secret 项目清单

| 键 | 用途/获取方式 |
| --- | --- |
| `FEISHU_APP_ID` / `FEISHU_APP_SECRET` | 营销物料管理自建应用，作为登录、Base、消息等应用身份；从公司开放平台/密码库移交 |
| `FEISHU_BITABLE_APP_TOKEN` | 主业务 Base 定位符，需同时具备资源权限 |
| `FEISHU_CORPORATE_APPAREL_SOURCE_APP_TOKEN` | 行政文化衫可写源 Base，而非只读同步表 |
| `FEISHU_BITABLE_WEB_URL` | 主 Base 页面地址（可选，按使用场景配置） |
| `FEISHU_APPROVAL_WRITEBACK_APP_ID` / `FEISHU_APPROVAL_WRITEBACK_APP_SECRET` | 现有审批回写应用/AnyCross 链路；以实际在用配置移交 |
| `CORPORATE_EXCHANGE_WEBHOOK_TOKEN` | 两个内部同步接口使用的高强度共享密钥；至少 32 字符；源表工作流和接收 API 必须相同 |
| `CLOUDFLARE_TUNNEL_TOKEN` | Named Tunnel 运行 Token；也可能保存在 Web Runner 单独 token 文件中 |
| `GITHUB_CACHE_REFRESH_TOKEN` | 代码中保留的缓存触发配置；不能代替 Windows Git 的仓库读写认证；按实际 CI 使用情况配置 |
| `STREAMLIT_APP_URL` | 历史命名的链接配置；如启用应指向正式公网地址，而非旧 Streamlit 地址 |
| `INVENTORY_VIEW_PASSWORD` / `APPROVAL_VIEW_PASSWORD` | 历史页面兼容配置，不是 React 物料管理入口的管理员认证机制；勿继续使用示例弱口令 |

旧控制中心主密码不是当前正式网页必需项，不恢复已删除的后台控制台。所有凭据由交接双方在安全渠道提供，本次只生成占位样例与键名清单。

## 飞书权限核对

当前企业身份校验读取应用所属 tenant，再比较登录人的 tenant_key。因此必须移交深圳市普渡所属的正确自建应用，而不是新建外部公司应用后仍期待验证同一企业。

应核对：企业信息读取 `tenant:tenant:readonly`；OAuth 及网页应用入口/回调；通讯录可见范围；Base 表读写、字段/自动化所需能力及目标资源授权；机器人能力和发送消息 `im:message:send_as_bot`；相关 IM 消息与资源读取；截图识别权限（若使用）；事件/卡片回调长连接；审批/回写应用；最后发布使配置生效。完整 scope 和数据范围以公司自建应用当前授权及实际接口为准，本清单不是保证覆盖所有 API 的最小权限声明。

**资源可编辑权限和应用 API scope 是两层授权。** 主 Base、行政文化衫源 Base、行政兑换源表、全球之旅/英文活动 Base 都要分别给“营销物料管理系统”应用授权，不能只给当前人的浏览器账号可编辑权限。

## 需要双方签收的账号/资源

- [ ] GitHub 私有仓库管理员/维护权限及 master 分支策略；计划任务账号能拉取，缓存账号能推送。
- [ ] 飞书自建应用维护人、应用发布权限、App Secret（安全渠道）、正确企业 tenant。
- [ ] 主 Base 和行政源 Base 的文档应用/协作者权限、字段配置、审批和自动化维护权限。
- [ ] Cloudflare 账号/Zone/域名所有权、Tunnel ID 与 Token（安全渠道）、DNS 权限。
- [ ] Windows 部署账号、服务器/电脑归属、电源与自动启动、备份和恢复负责人。
- [ ] 群/人员通知可达范围、管理员和 HR 接收名单的权限表维护责任。
- [ ] 原电脑撤权/密钥轮换时机：新节点验收通过后进行，避免提前失效造成停机。

本包不保存网页登录 Cookie、Windows 密码、Git credential store、Cloudflare 登录证书或个人访问令牌。
