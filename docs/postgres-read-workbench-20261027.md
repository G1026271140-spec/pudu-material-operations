# V3.6.1：数据库读取与表格工作台

本次范围：完成初始数据导入、页面从 PostgreSQL 读取，以及应用内管理员表格查看与单元格编辑。发货模板、发货排期维持原实现。

## 已验证的数据接入

- 23 张来源表、358 个字段，初始导入 5,452 条业务记录；另有 2,127 位人员、205 个部门。
- 原始字段 JSON 与类型化 SQL 列一并保存；按来源表 ID、字段 ID、记录 ID 对应。
- 每张表均比对数据库记录数量和原始字段内容的 SHA-256；所有表一致。兼容飞书嵌套关联格式后复核，来源历史数据有 5 处关联指向当前来源表中不存在的记录（涉及 3 个字段）；保留原始引用，不自动删除历史数据，独立报告位于虚拟机 shared/pg-link-audit-20261027.json。
- 初始导入拒绝覆盖本地待同步修改；分页失败或字段定义不一致会阻止发布不完整快照。
- 原始业务记录、人员信息及数据库备份保留在虚拟机，未加入 Git。

## 应用内入口

访问 `/management/database`，或在管理员左侧“数据与系统工具”中选择“数据库工作台”。沿用飞书真实登录及已启用的管理员权限，未新增绕过登录的入口。

- 左侧切换来源表，支持搜索、分页、按字段排序、选择显示字段。
- 双击单元格或按 Enter 编辑；支持文本、数字、单选、多选、日期、复选框、人员、关联和品类图片。
- Enter/离开单元格保存，Esc 放弃；复杂选项在选择器中保存。
- 公式只读，提供可编辑来源字段入口；物料维度名称由对应关联字段维护。
- 系统编号、任务处理、审批/发放等流程字段按业务规则保护；工作台不是任意 SQL 控制台。
- 库存调整校验非负整数，并在同一事务中生成库存流水、字段审计和待同步任务。
- 修改关联时维护反向关联；修改品类/维度名称时更新当前库存标签，保留历史申请快照。
- 记录版本防止覆盖他人修改；重复保存标识幂等处理；保留至少一名启用的管理员。
- 品类图片可添加、移除和清空，保留 GLB/HTML 等其他附件；新图片在飞书同步之前可从本地显示。

## 数据来源与保存状态

网页业务数据来自 PostgreSQL，同一响应使用一致的数据库快照，请求结束后归还连接。普通申领、文化周边及文化衫页面按版本检查更新目录，保留正在填写的表单。

工作台修改先保存本地数据库，业务值、审计和 outbox 同事务提交。界面明确显示“本地已保存 · 待同步”。本阶段尚未启用飞书同步 Worker 和每天北京时间 03:00 的校验作业，普通申请/配货提交仍保持关闭。

## 部署与回退

虚拟机服务使用以下开关，凭据继续放在原外置配置中：

```text
PUDU_DATA_SOURCE=postgresql
PUDU_DATABASE_DSN=dbname=pudu_materials
PUDU_DB_EDITOR_ENABLED=1
PUDU_WEB_READ_ONLY=1
PUDU_MEDIA_ROOT=/home/gaohongyuan1/pudu-materials-operation/shared/media
```

连接通过本机 Unix socket，应用连接池上限 5。媒体写目录以 systemd `ReadWritePaths` 单独放行。

发布以独立 release 目录和 `source` 符号链接切换；保留旧 release 和数据库备份。回退应用时保留 PostgreSQL、审计和 outbox；本地未同步修改不能通过重建或覆盖数据库丢弃。

后续阶段接通申请业务写入、普通/文化周边两通道、飞书同步幂等与重试，再启用 03:00 飞书优先的字段级校验。
