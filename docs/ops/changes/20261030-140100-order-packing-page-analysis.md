## 推荐页面与生成规则

- 仅管理员，在物料管理中新增“下单与分装”。沿用现有日历的月份 / 日期切换、申请卡片、单据详情与品类分组样式。
- 默认查看已核实库存的有效普通物料申请；未核实、取消、驳回、撤回及失效明细不得静默纳入。是否开放未核实申请应另行明确。日期和历史查询可切换，不直接复用发货状态作为导出状态。
- 支持单据复选、整日选择、全选当前筛选结果、清空、跨日期 / 搜索 / 翻页保留选中；可展开确认印刷物料明细。没有印刷物料的申请清楚标明原因。
- 固定选择栏显示已选申请数、规格数、总数量；预览下单表 / 分装表，再生成一个 Excel 的两张工作表。
- 两表均采用类型、物料名称、语种、数量、用途五列。下单按稳定物料规格合计，逐申请保留数量和用途说明；制作备注不同的物料保留区别。分装按申请单和用途成组，组内按品类 / 型号 / 语种展示，E 列合并用途并保留单号可追溯。不同单据即使用途相同也保留分配归属。
- 数量采用当前有效配货明细，已调整配货优先使用调整后的规格和数量，排除零量及已撤回明细，不能从现在库存重新倒算或扣减。
- 只以品类定义过滤印刷物料，名称中含“产品”或“手册”不等于定义命中；本地与远端记录 ID 统一映射，不能重复计入同一明细。
- 读取 PostgreSQL，生成前核对所选明细版本；多人修改后提示重新预览。生成保存来源快照和本地导出历史，历史重下载使用快照，改动后可另生成新版本。
- 本功能为资料导出，沿用现有配货 / 库存 / 审批流程，不因下载重复登记下单或触发自动补库；大量单据可后台生成并显示进度，不进入飞书数据同步队列。
