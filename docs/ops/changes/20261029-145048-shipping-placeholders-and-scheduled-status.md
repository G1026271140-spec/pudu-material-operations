## 规则与实现

普通物料申请在 PostgreSQL 创建申请头时加入默认物流文字和共用示例媒体，同事务产生 outbox。仅缺失 / 空值填默认，保留已有真实物流；不修改历史申请。示例为项目内确定性文本图，明确“示例图片 / 发货图片待补充 / 请在发货时替换为实际图片”，不是真实发货凭证。默认图仅一份媒体，上传后复用飞书 token。

自动发货通知将“待补充”视为空物流文字，通过稳定本地媒体 ID / 对应飞书 token 排除示例图；不会因占位而误发通知。真实文字或真实图片任意一项即按原审批规则通知；审批通过勾选已发货不变。

contacts.refresh_now 只在成功刷新后写心跳，是定时 / 按需任务。只读核对 service 上次 ExecMainStatus=0、timer active、下次北京时间 2026-10-30 03:10；之前用两分钟常驻心跳规则误报。新界面把它单列为定时刷新，显示上次完成及当时版本；常驻服务分母不含它，没有无意义重启或强刷通讯录。
