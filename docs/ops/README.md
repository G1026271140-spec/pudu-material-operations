## 两条常用命令

以 `gaohongyuan1` 登录虚拟机后，只读巡检：

```bash
cd /home/gaohongyuan1/pudu-materials-operation/source
/home/gaohongyuan1/pudu-materials-operation/venv/bin/python scripts/ops_status.py
```

在**本人的工作目录**完成提交后发布：

```bash
cd /srv/pudu-materials-workspaces/"$(id -un)"
sudo pudu-release
```

`source` 是正在运行的不可变发布，不能在里面改代码。交接包源码是时间点快照；开始工作前必须核对 GitLab 和线上，不可用整个快照覆盖虚拟机。

本目录和根目录 `AGENTS.md` 随代码提交 GitLab。每次完成需求还须写 `docs/ops/changes`，有新规则时同时更新本手册。原始对话的受限档案单独移交，凭据与生产数据库备份不在源码包中。
