## 被后续要求替换的内容

- 用户曾要求管理 / 配货 / 发货完成给管理员发结果消息，随后多次明确删除额外成功回执；**以后者为准**，失败提醒继续保留。
- 分装曾使用语种规格卡片，用户进一步明确为型号框选池，上方表格改语种 / 数量 / 比例；以最后方案为准。
- “数据与系统工具”是旧分组名称，现为历史数据 / 后台编辑 / 系统工具三组。
- 最初只做企业文化衫整单驳回，后扩展文化衫和文化周边选择明细部分驳回；原描述不能限制新功能。
- 初期要求网页实时读飞书，后来决定 PG 为日常主库、每日飞书校验；不能恢复每次页面全表读飞书。
- “直接改虚拟机代码”已细化为个人 VM 工作区修改、提交 GitLab、统一发布；不是修改正在运行的不可变 source。
- 用户已自行完成 GitLab 组织内可见性调整，不重复更改项目权限。
