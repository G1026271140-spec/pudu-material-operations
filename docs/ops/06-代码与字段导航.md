## 稳定字段与 SQL

1. `config/feishu_field_registry.json`：来源、稳定 table_id / field_id、显示名、类型、选项及关联表。
2. `material_meta.tables / fields`：实际注册元数据；`material_data.t_<table_id>`：一表一 SQL 投影。
3. `_record_key` 为稳定本地键，`_remote_id` 为飞书 ID；本地新记录可先没有 remote_id。
4. `_fields` 保存业务字段、`_baseline` 保存源基线，`_local_version / _synced_version / _sync_state / _deleted` 维护同步；不能为了修界面手工重建这些状态。
5. `material_ops` 保存 outbox、jobs、effects、audit、reconcile_runs、media 等；`config` 不是生产数据备份。
6. `deployment/postgres/001..010` 是历史增量迁移，按前置条件和当前 schema 应用；迁移的 schema owner 是 `pudu_material_owner`，应用账号不临时升为表结构管理员。

本次基准为 **23 张来源表、366 个注册字段**。009 是行政源表的 4 个申领设置字段，010 将主来源镜像对应的 4 个字段补齐；同名字段位于不同来源，不能只按中文显示名认定已注册。
